// DAA — ALGORITHMS POWERING THIS GAME
Deque
O(1) push & pop
Snake body stored as a double-ended queue. Head is pushed to front on move; tail is popped from back. Constant time operations.
Hash Set
O(1) lookup
All snake body positions stored in a hash set. Collision detection (wall & self) happens in constant O(1) time per tick.
Fisher-Yates Shuffle
O(n) shuffle
Food and poison spawn positions are randomly sampled from free grid cells using the Fisher-Yates algorithm for unbiased randomness.
BFS Pathfinding
O(V + E)
Press H in-game to trigger BFS. The shortest path from snake head to the nearest food is computed and displayed as an AI hint overlay.
Greedy Heuristic
O(4) per step
Scores each of the 4 possible directions using Manhattan distance to rewards and penalties for poisons and walls. Picks the best move.
Priority Queue (Min-Heap)
O(log n)
Items (food & poison) are tracked by spawn time in a min-heap priority queue. Expired items are efficiently removed each game tick.

ABOUT THE PROJECT

SERPENT is a DAA-powered Snake Game built as a Design & Analysis of Algorithms project. Every mechanic inside the engine is backed by a real algorithmic concept — from how the snake body is stored, to how food spawns, to how collisions are detected.

The game demonstrates Deque operations, Hash Set lookups, Fisher-Yates shuffling, BFS pathfinding, Greedy heuristics, and Priority Queue item management — all in real time as you play.

Built with pure HTML, CSS, and JavaScript. No frameworks. No libraries. Just algorithms.
